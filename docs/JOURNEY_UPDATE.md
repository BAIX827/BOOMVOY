# BOOMVOY 操作动线更新 · 2026-10-12

旅行导航收拢为「总览 / 行程 / 准备 / 账本 / 更多」。旧页面地址继续可用，相关页面通过分组导航进入。

## 用户操作

- 首页提供继续规划或打开今天的入口；总览根据旅行日期、空白日程、住宿、待预订订单、行李与 AA 结算显示下一步。
- 日程、地图、天气共用当前日期。链接携带 `day` 和选中的 `place`，每次旅行的日期选择保存在本机；旅途中通过总览直接打开今天。
- 创建旅行填完目的地和日期后，可使用默认偏好直接创建；人数、预算、主题可以在旅行设置调整。
- 收藏可安排进指定日期。酒店安排入住和退房日期，并建立待预订记录；住宿按实际覆盖的夜晚显示。
- 日程的添加地点、从收藏加入、查看地图在地点列表上方；推荐与辅助工具按需展开。手动添加地点立即入列，定位随后补全。
- 地图编号跟随行程顺序，近距离编号自动避让，路线箭头指示方向，选中地点与列表联动。估算路线使用虚线；后台路线请求最多四路并发。
- 已登记订单优先展示，供应商搜索入口可以展开。关联订单的预订、付款、取消、日期变更会更新收藏和行程状态。
- 就近排序先预览，保留已订、打卡、照片和感受所在的地点位置，提示时间冲突；应用排序和删除地点支持撤销，后续编辑会使旧撤销失效。
- 分享提供行程文件导出以及浏览器打印 / 保存 PDF。行程文件省略照片、感受、订单确认号、支出账本和私人备注；接收方在「我 → 导入备份」追加旅行，保留已有旅行和个人设置。同 ID 的旅行跳过，避免重复导入。完整本机备份仍沿用原有恢复行为。

## 数据关联

`PlaceStop` 新增可选 `sourceSavedId` 和 `bookingId`，`DayPlan` 新增可选 `stayBookingId`。浏览器和 Node 快照服务同步支持这些字段，旧数据继续有效。关联只依据明确 ID 和日期，不按同名地点推断订单。

## 验证

运行 `npm test`、`npm run build` 和 `git diff --check`。新增 `tests/journey.test.ts` 检查日期恢复、下一步判断、重复安排、订单状态与日期变更、住宿范围、同步字段、受保护排序，以及分享文件的字段过滤和导入格式。

浏览器在独立本地端口验证快速创建、收藏指定日期、住宿订单、状态同步、日期在地图与日程之间传递，以及手机和桌面布局。
